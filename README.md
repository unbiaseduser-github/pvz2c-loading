# pvz2c-loading
Have you ever played Chinese PvZ2, seen the loading overlay that blocks the entire screen a billion
times and thought "hmm, I want that in my app"? You're in luck! Now with Compose support so you can
block users the Modern Android Development™ way!

# Project state
This is a POC. Releases are not planned yet. The library is small enough you can just copy the code
to your project, if you want to use it for whatever reason.

# Disclaimer
- This is a "clean room" recreation. No game assets are used in the making of this library.
- This whole project is a joke (with real results though).

# Features
- Authentic-esque PvZ2C loading look and feel, fine-tuned by yours truly
- No [Horrible Level Design](https://www.youtube.com/watch?v=arIYaS5-D6A) included
- No internet permission required
- Custom loading text, so you're not limited to `[NET_CONNECTING]` (or whatever the actual lawnstring
key is, the last time I kept track of 2C was like in 2024.)

# Limitations
- I do not provide support for playing the actual game. Seriously, I can't bypass China's ID
verification system in the first place.
